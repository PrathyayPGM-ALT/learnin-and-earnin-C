## 🤓 What I *think* I've learned so far

###  `#include <stdio.h>`
Not “studio.h”.  
Not “stadio.h”.

###  `int main(void)`
The function where everything begins,  
and also where everything goes wrong.

Returns `0` for “success”.  
Returns nothing if you enjoy compiler disappointment.
